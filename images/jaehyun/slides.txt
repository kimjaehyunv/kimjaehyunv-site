# ============================================================
# JAEHYUN 페이지 — 슬라이드 목록
# ============================================================
#
# 이 파일만 수정하면 JAEHYUN 페이지 사진 순서와 구성이 바뀝니다.
# gallery.json 은 직접 수정하지 마세요. Update Gallery.command 로 자동 생성됩니다.
#
# ── 기본 규칙 ──
#   • 한 줄 = 슬라이드 한 장 (위에서 아래 = 사이트에서 보이는 순서)
#   • 파일명만 적으면 사진 한 장짜리 슬라이드
#   • + 로 이으면 여러 장을 한 슬라이드에 묶음
#   • # 으로 시작하는 줄은 메모 (무시됨)
#
# ── JAEHYUN 전용 키워드 (대괄호) ──
#   [opening]        첫 장 강조 크기
#   [closing]        마지막 장 강조 크기
#   [reduced]        작게 표시
#   [reduced-forty]  더 작게 표시
#   [small]          작은 크기
#   [lower-left]     왼쪽 아래 배치
#   [contact]        4장 contact sheet (예: 19+20+21+22)
#   [pair]           2장 비대칭 pair (예: 26+27)
#
# ── 02a / 02b 사용법 ──
#   한 슬라이드에 두 장:  [pair] 02a.jpg + 02b.jpg
#   각각 별도 슬라이드:   02a.jpg  (한 줄) / 02b.jpg  (다음 줄)
#
# ── 파일 이름 규칙 ──
#   01.jpg, 02a.jpg, 02b.jpg, 06.JPG 처럼 번호 + 선택적 알파벳 접미사
#   .jpg 와 .JPG 둘 다 사용 가능 (slides.txt 에 적은 이름과 파일명을 일치시킬 것)
#   순서는 이 파일의 줄 순서가 기준입니다
#
# ── 사진 추가/삭제/순서 변경 후 ──
#   1) images/jaehyun/ 폴더에 사진 파일 추가 또는 삭제
#   2) 이 파일(slides.txt) 수정
#   3) Update Gallery.command 더블클릭
#
# ============================================================
